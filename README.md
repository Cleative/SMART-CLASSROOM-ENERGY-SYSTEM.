# Smart Classroom Energy System

A beginner-friendly Decision Tree classification demonstration that recommends classroom lighting actions from four manually entered inputs. It does **not** control hardware.

## Important limitation
The included dataset is synthetic. Labels are generated by the transparent demonstration policy and are not human-verified ground truth. High test scores measure agreement with this policy, not proven real-world accuracy or electricity savings.

## Requirements
- Windows 10/11
- Python 3.11 recommended
- Visual Studio Code (optional)
- Internet only to install dependencies or optionally download the public occupancy dataset

## Windows installation (PowerShell)
Extract the ZIP, open PowerShell in `Smart_Classroom_Energy_System`, then run:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m src.generate_dataset
python -m src.validate_data
python -m src.train_model
python -m src.evaluate_model
pytest -q
streamlit run app.py
```

If PowerShell blocks activation, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` in that terminal and activate again. Alternatively use Command Prompt: `.venv\\Scripts\\activate.bat`.

## Notebook
Open `notebooks/Smart_Classroom_Energy_System.ipynb` in VS Code or Jupyter from the extracted project folder. Run cells in order. Install dependencies first.

## Policy
Recommendation is ON only if all are true: `scheduled_day == 1`, `motion_detected == 1`, `hour_of_day >= 7`, `hour_of_day < 18`, and `light_level_lux < 400`. Otherwise OFF. Therefore 18:00 and exactly 400 lux both yield OFF.

## Optional public data
Run `python -m src.fetch_public_dataset` when online. Downloaded files are kept in `data/public/` and ignored by Git. Occupancy labels are not lighting labels and are not substituted into model training.

## Streamlit Community Cloud deployment
1. Create a GitHub repository and upload the contents of this project folder (including `app.py`, `src/`, `models/`, and `results/`).
2. Ensure `requirements.txt` is in the repository root. Do not upload `.venv/`, credentials, or private data.
3. In Streamlit Community Cloud, create an app, select the repository and branch, and set the main file path to `app.py`.
4. Deploy. The app loads the included model artifact and does not retrain or download data at startup.
5. If dependencies fail, confirm Python and pinned package compatibility. If the model is missing, confirm `models/decision_tree.joblib` and `models/model_metadata.json` were committed. If app imports fail, confirm `src/__init__.py` exists and the repository root is selected.

Deployment has not been performed by this project-generation process; follow the steps above to deploy it.

## Retrain
After regenerating or replacing the processed dataset, run:
`python -m src.train_model` then `python -m src.evaluate_model`.

## Tests
Run `pytest -q`. Tests validate policy boundaries, dataset reproducibility and schema, model loading and predictions, invalid inputs, and path independence.
